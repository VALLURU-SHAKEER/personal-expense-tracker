## Project Description

The Personal Expense Tracker is a web application developed using HTML, CSS, and JavaScript. It helps users record and manage their daily expenses.

Users can add expenses with their name, amount, date, and category. The application displays the total expenses, allows users to delete expenses, filters expenses by category, and saves expense details using browser Local Storage.

## Main Features

1. Add daily expenses with name, amount, date, and category.
2. Calculate and display total expenses in Indian Rupees (₹).
3. Delete unwanted expense records.
4. Filter expenses by category.
5. Save expense details using browser Local Storage.
6. Track project changes using Git and GitHub.
7. Manage issues, feature branches, and pull requests.
