# Personal Expense Tracker

## Project Description
The Personal Expense Tracker is a simple web application that helps users record expenses, view total spending, and filter expenses by category.

## Features
- Add expenses with name, amount, date, and category.
- View the total expenses.
- Save expenses in browser Local Storage.
- Delete expenses.
- Filter expenses by category.
