# Personal Expense Tracker

## Project Description
Personal Expense Tracker is a simple web application that helps users manage their expenses. Users can add expenses, view their total spending, save records, and filter expenses by category.

## Features
- Add expenses with name, amount, date, and category.
- Display total expenses in Indian Rupees (₹).
- Save expenses using browser Local Storage.
- Delete expenses.
- Filter expense history by category.
- Display expense history with dates.

## How to Run
1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Add expenses and select a category to filter the history.
